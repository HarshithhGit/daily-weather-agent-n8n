# 🌤️ Daily Weather Automation with n8n

An automated weather reporting workflow built using **n8n**, **OpenWeatherMap API**, **Google Sheets**, and **Gmail**.

## Features

- Fetches live weather data using OpenWeatherMap
- Stores weather history in Google Sheets
- Sends a formatted weather report via Gmail
- Runs on a scheduled trigger
- Easy to customize for different cities

## Workflow

Schedule Trigger
↓
OpenWeatherMap
↓
Google Sheets
↓
Gmail

## Tech Stack

- n8n
- OpenWeatherMap API
- Google Sheets
- Gmail API
